# Counts, windows, dates and the symptom lists: what a number on a surface may claim.

Loaded when a session reads a file under these paths. Each rule keeps its guard and its pointer into `docs/engineering-lessons.md`; a guarded rule fails CI wherever its text lives. Same standing as `CLAUDE.md` (Tier 1).

- **A COMPLETENESS ratio beside a PARTIAL enumeration is a claim about the enumeration (CUL-62); a COUNT spoken as a record fact is never derived from a DISPLAY WINDOW (CUL-223):** render a coverage density as the un-logged days only, and nothing when fully covered; put the scope where the reader meets the claim; never gate a coverage fact on the thing being counted; use the predicate the neighbouring sentence uses. A number that labels a destination counts what the destination holds: the window may INDEX, only the total may be SPOKEN, in separate variables. A mutation that does not change behaviour has not tested the guard. _(full account: `docs/engineering-lessons.md` §C-3)_
- **Two counts over ONE population must partition it; PRECEDENCE is the only honest resolution (CUL-746):** the reason lives in one function both surfaces switch on (`exposureReasonOf`, consumed by `exposureBreakdown`), so inverting it reds both pages' guards. Fix the accusing branch before the reassuring one; any field that decides a row's stated reason joins the group key; a reason may outrank another only when the loser is the misleading half; where the record cannot settle a question the page must not answer it (the numerator question is CUL-758). A guard containing `.*` is not a guard — slice the object under test and anchor the match. A review subagent shares your working tree: tell it to `cp -r` before mutating, and snapshot first. _(full account: `docs/engineering-lessons.md` §C-4)_
- **Symptom-key lists are discovered, decided, and guarded (CUL-676):** any array / Set / Record enumerating ≥3 symptom leaf keys must be registered in `guards/symptomLists.test.ts` AND carry a per-leaf decision row in the §13a membership walk (`constants/eventTypes.membership.test.ts`); the guard fails the build on an unregistered list (exemption `// symptom-list-ok: <reason>`). A transitive consumer is invisible to the scan — name it in the walk row of the list it rides on; registration without a walk row is half-registration. _(full account: `docs/engineering-lessons.md` §C-11)_
- **A MIRRORED constant must answer the same QUESTION, and a header that claims a wiring is asserted or deleted (CUL-873):** a number copied from another module inherits that module's question, not just its value — `lib/lookWithheld.ts`'s recency bound mirrored the intake detector's two days, and a *finding* that may go quiet as its evidence ages became a *suppression* that stopped protecting a cat 49 hours into a hunger strike. Same value + same question → mirror it and name the source; same value + different question → two constants, each with its derivation written down, even when equal today. And a comment asserting module A reaches module B is a claim the build must check: `lib/lookWithheld.ts` said the emergency door took `intakeArm` and nothing imported it, while the card's own mock stubbed the fold to a passthrough — so a mock standing in for a pure function uses `jest.requireActual`; the read is what needs stubbing, never the rule. A test that re-derives the production rule to check it is a tautology with fixtures (deleting the bound left 7,576 of 7,577 tests green): drive the real function and derive the fixture's boundary from the shipped constant. _(full account: `docs/engineering-lessons.md` §C-34)_
- **A shared predicate inherits its CALLER'S window, and a fixture that cannot exist in production is green over nothing (CUL-874):** a module written over "the record" is only as true as the read behind it — Patterns handed `lookComparison` 56 days, 56 days back is the same index the earlier half starts on, and the regression-to-the-mean guard silently became a TAUTOLOGY that withheld every falling pair with a false sentence and hid §6.6's density rule behind it. The same read bounded the onset date, so a two-month-old concern printed as three days old and disagreed with the two surfaces that read unbounded. So: a predicate about the record takes the record (the widest read its narrowest claim needs), every count bounds itself internally (C-3), and a GATE's window is the window of the CLAIM IT GATES, never the convenient neighbour's — CUL-845's zero-suppression read 28 days against symptom cards that count 30 and say so in their caption, leaving a two-day hole exactly where the gate exists. The gate's DIRECTION is likewise the reader's: it asks "can this read as improvement", and the reader is looking at two numerators, so it switches on the COUNT even where the rate is the honest way to describe the trend. **And the tests could not see any of it, because every one of them seeded a row 70 days back to disarm the guard** — a row the 56-day read cannot produce. A fixture shaped unlike production is green over a shape production never creates; build one the caller could actually hand over. A survived mutant is not always a test gap, either: one here replaced a guard clause and left the argument beside it, so it changed no behaviour. _(full account: `docs/engineering-lessons.md` §C-35)_
- **A DATE may reach outside the window when a COUNT may not, and the sentence holding both says which is which; a DEFAULT on a privacy decision is that decision (CUL-875):** C-19 makes a record-anchored date free and a duration guarded, so one sentence legitimately mixes spans — and must then NAME each: *off on 3 (first marked Jul 10, before this window)* beside a window-scoped count, or the two merge and a 67-day relapsing problem prints as 13 days old. Where the read behind the date may be truncated, scope it to the query (*earliest here*), never to the record. The tell for this class is asymmetry: **if you reach outside the window, check you reach for the accusing number too.** Also from this pass: a falsy catch-all that names one of its members lies about the others (an unrecognised word key is not "an activity"); an empty return with several causes makes the caller guess wrong (*Too few days answered (41 of 46)* over a record that simply had nothing wrong) — return the REASON; and a floor never suppresses a protection while keeping its claim (the absence caveat lived inside the bar block the floor removes). **And the default:** a discriminated union whose share-link arm carries no notes field makes the leak un-writable — until a wrapper gives the parameter a DEFAULT, which hands it over for writing nothing; required, ahead of the optionals. Two rules here were string literals nothing red-flagged (the `deleted_at` embed that is an undone note's only guard; §9 rule 4's mint), so `guards/reportLookPull.test.ts` pins the first and registers the second with the empty set as the assertion (C-32). _(full account: `docs/engineering-lessons.md` §C-37)_
- **A record-anchored DATE is free; a DURATION is guarded (CUL-69):** re-anchoring a claim to the record's earliest entry costs nothing as a date, but a duration inherits the detection engine's floors or is DISCLOSED beside the engine's span — never re-derived at the render layer. A year-less date is safe only inside a bounded range; stamp the year once per band, never per date or conditionally; a pointer to another section is not a licence to generalise. On a safety surface re-run the falsification pass after every correction and prove each new guard by mutation. _(full account: `docs/engineering-lessons.md` §C-19)_
