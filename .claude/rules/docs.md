# Docs and mock rounds: versioning, correcting a frozen brief, and how a mock round publishes.

Loaded when a session reads a file under `docs/`. Same standing as `CLAUDE.md` (Tier 1); the Tier rules themselves stay in `CLAUDE.md` § Documentation Update Protocol.

**Doc versioning — living vs. frozen (instituted 2026-07-19 retro).** *Living references* (`nyx-technical-spec`, `nyx-schema`, `nyx-design-principles`, the `*-requirements.md` specs) carry their version in the **header** and bump the `Last Updated` date on any material edit — never bake the version into the *filename*. *Frozen point-in-time artifacts* (research dossiers, dated `docs/research/` briefs, strategy records, competitive snapshots) are **not** version-bumped — a date stamp is honest, and editing them in place destroys the "what we knew when" record. **How you correct a frozen brief, then (2026-08-30, CUL-671): additively, never in place.** A dated verification-pass section at the foot (`§V`) carries the corrections, and every corrected claim keeps its published wording and gains an **inline ⚠ pointer** to the row that corrects it — the §9b shape the taxonomy spec already uses. Both halves are load-bearing. Re-verify a **competitor** sweep at use, not at citation. _(what CUL-671's corrections showed: `docs/engineering-lessons.md` §P-17)_

**Design mocks are Artifacts, and a mock round re-publishes to the SAME URL (2026-07-31).** The committed `docs/culprit-<track>-mockups.html` is the source of truth; the published Artifact is how the PM looks at it. Round N+1 re-publishes over round N's URL (pass `url`, or the same `file_path` inside one session); keep the `<title>` and favicon stable, name the round inside the page, and say in the page when a round supersedes an earlier one. `Artifact({action: 'list'})` recovers a URL a later session no longer has.

**When rounds stop being legible, split current from archive (2026-08-15, PM directive).** Past ~4–5 rounds on one page the PM cannot tell the live proposal from superseded frames, so split: a **current-proposal page** (`docs/culprit-<surface>-mockups.html`, its own URL; frames replaced in place, git is the history) and the old page as the **deliberation archive** (banner + link to current). Split at the moment a reaction round confuses current with legacy, not before. First instance: `culprit-daily-recap-mockups.html` (current) + `culprit-notifications-mockups.html` (archive).

**A reaction round republishes as ONE proposal (2026-09-09, PM directive on the daily look: "sometimes we mix in elements from mock-a to mock-b and it gets confusing which is current state").** When the PM has reacted to a side-by-side round, the next round is not a second side-by-side: the retired directions **leave the page** (git keeps them; the page names the commit), every alternative that is still a real decision sits in a **labelled box** (*option, drawn for the decision, not the current proposal*) beside the frame it competes with, every current frame carries a *current* tag, and a **ledger at the top maps each reaction to what it ruled and what moved on the page** (a reaction that was a clarification, not a change, says so in the ledger rather than silently). First instance: `culprit-daily-look-mockups.html` round 2 (CUL-840).

**A build ready round keeps the mock round contract (CUL-1894, 2026-10-23).** The round a spec or build is cut from carries `<meta name="mock-round" content="build-ready">`, and: (1) every element in a frame names its kit primitive and token, `data-kit="Card · colorSurface, shadow-card"`, or `data-kit="new: <Name>"` for a part the kit lacks; (2) every colour, size and shadow is a `var(--token)` from `docs/mockups/theme.css`, never a typed value; the file is generated from `constants/theme.ts` (regenerate: `node --no-warnings scripts/mockup-theme/emit.ts`) and publishes beside the page (`files: {"mockups/theme.css": "docs/mockups/theme.css"}`); (3) it draws the state set: empty, loading, failed or offline, 320pt, largest text, two pets, VoiceOver order, and the PM's real payload. An exploratory round stays free. `/design-critique`'s `contract` lens checks it. _(why: `docs/engineering-lessons.md` §P-18)_
