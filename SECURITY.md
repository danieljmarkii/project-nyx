# Security

## Reporting a vulnerability

Email **support@getculprit.app** with "Security" in the subject line. Say what you found, how to reproduce it, and what it could expose.

Please report it privately: don't open a public issue or pull request about it, and don't test against accounts or data that aren't yours.

## Scope

- The Culprit iOS app, built from this repository.
- Its Supabase backend: the database and its row-level security policies, file storage, and the Edge Functions under `supabase/functions/`.

## What happens next

Every report is read, and you get a reply at the address you wrote from. A report that could expose a pet's health record or an owner's account is handled first.
