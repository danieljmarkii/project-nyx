# Process retros

One file per retro, `YYYY-MM-DD-retro.md`. The SessionStart hook counts session records newer than the newest file here and prints `RETRO DUE` at 10. Writing a retro file is what resets the counter, so a retro that is not written down did not happen.

Method and the four questions: `docs/operating-model.md` §7 and `/retro`.
