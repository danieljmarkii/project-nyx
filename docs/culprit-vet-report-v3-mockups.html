Why this shape. The subject carries pet, surname, the reason and, when one is live, the flag in plain words: the front desk reads the subject first and phones the owner the same hour. It is sent from the owner’s own address through the phone’s Mail, so it matches the client and does not look like phishing. No marketing footer, no tracking, no link as the only copy.

The filename names an owner home log, never a “vet report”: a classifier that files it as an outside vet record treats its contents as clinician-authored. ASCII, ISO dates, the PDF Title set to the same string. No flag in the filename, because a filename lasts forever and a flag is stale tomorrow.
