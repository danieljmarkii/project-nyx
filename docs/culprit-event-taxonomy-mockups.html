01 · The grouped picker — does the grid scale?

Families as groups, leaves as tiles, at both densities

Families land exactly as §3 says: new groups in the B-745 grid, not a redesign. Group names are owner language, not spec taxonomy — "Breathing," never "Respiratory"; the urinary family splits its group label by species ("Litter box" for a cat, "Peeing" for a dog) exactly as §3's copy-level conditionality allows. Symptom families keep the rose tint everywhere — §6 makes SYMPTOM_TYPES the one tint predicate, and tints are identity, never verdict. A per-family rainbow was considered and rejected: it would dilute the rose-means-symptom signal History and Today already teach, and the group headers carry the wayfinding instead.

Two proposals are visible here and flagged for reaction rather than slipped in: the existing "Symptoms" group becomes "Tummy" (vomit + stool) with Lethargy moving to "Energy & behavior" — family names are constants-layer presentation, so the regroup is free — and the existing Itch/Scratch tile relocates into "Skin & coat" as "Scratching" when that family arrives at W3. Which enum value that tile writes (itch today, the dormant scratch carries the engine membership) is a W3 build decision, deliberately not made here: to an owner they are one observable, so it stays one tile either way.

The scale verdict this round asks you to confirm: the grouped grid holds to full spine — but only with all four of these in place. (1) Group headers do the wayfinding (a flat 28-tile grid would not survive the 10-second test; 12 named groups in stable order does). (2) The order is frequency-honest: Tummy, Breathing, and the litter family sit in the first two screens; the long tail scrolls. (3) Spatial stability is absolute — no per-pet reshuffling, ever (§6); the only adaptive element on the table is the bounded "frequent" row in §06. (4) The full spine arrives over four-plus waves, each its own greenlight — nobody wakes up to 28 tiles; the grid grows a family at a time, and W1 adds exactly two tiles to today's picker.

02 · The confirm — B-745 register inheritance

Cough and sneeze confirm: deliberately boring, with two honest deltas

§14 predicted this frame "should be boring," and it is — the one-surface confirm, the summary-pill save, the teal register, all inherited untouched. The per-leaf contract shows up as two absences: no photo row (a cough has nothing to photograph — §6's per-leaf hasPhoto, so the zone never renders), and no Saw it / Found it chips. A vomit can be found on the rug at 5 PM; a cough cannot be found — it is heard or it is nothing, so the row writes witnessed by construction and one chip pair disappears rather than asking a question with only one honest answer. That is the CUL-606 lesson applied forward: withholding an affordance is cheap; one that stamps a claim the record cannot hold is not. Decision brief R3 below generalizes the split.

03 · The D4 decision — ruled at this round

The straining cluster, rendered both ways

The setup, common to both options: Juniper (male cat) has three urine_strain rows since 2 PM, each with the optional "Did any pee come out?" chip marked No. The cluster rule is deterministic — ≥3 marked-unproductive strains inside a rolling window (the numbers here are placeholders; W2's Dr. Chen falsification pass owns the calibration) — and it fires only on explicit "No" marks: an unanswered chip never counts as "nothing passed" (the B-027 absence-of-log guard, applied before this rule ever ships). Both options render the Signal safety card; the question D4 asks is whether capture also speaks at the moment the third log lands. Copy conditions on pets.sex — Juniper is male, so the line names it; for sex = 'unknown' it reads "…can mean a blockage, and for a male cat that's an emergency."

04 · The breath counter — a new capture primitive

Thirty seconds, one tap per breath, in the calm register

respiratory_rate is the spine's one new primitive: a guided measurement (the Cardalis shape), structurally the weight_check pattern — an events row plus the measured value in a child table. It is a measurement, not a symptom: neutral tint, no rose anywhere, and the moment is designed calm — Sam counting a sleeping cat's breaths is a quiet ritual, not an emergency drill. The app does the arithmetic; the owner only taps. Canceling discards cleanly — no partial rows.

05 · The detail screen — the §7 contract, redesigned

Record facts first, identity always named, Remove out of Edit's reach

Today's event/[id] leads every event with the photo hero — even an empty "Add a photo" zone on events that will never have one — and closes with Edit as the loudest element on screen, Remove directly beside it (the CUL-612 destructive-adjacency class). The redesign inverts the hierarchy per §7: identity (leaf label + family tint — never a bare "OTHER" kicker; an unknown type renders "Event" with the fallback glyph, label-safe by contract), then the record facts in History-parity wording, then photo and AI read only where the leaf carries them, then attributes and notes, with Edit demoted to a quiet row and Remove alone at the bottom behind its own confirm. One screen, two leaves, so the per-leaf contract is visible as a diff.

06 · The Designer's exploration — "frequent for this pet"

One bounded row, and the grid below it never moves

§6 bounded the C2 study's personal-frequency idea to at most a row, because a grid that reorders itself fights 3am muscle memory. This is that row, drawn so it can be judged: three compact tiles from the pet's own recent logging, above the groups, additive only — every tile keeps its permanent home in the grid below, in the same place it always is. The row appears only once the pet has enough history to earn it and never contains a tile the grid doesn't.

07 · React — the decisions this round carries

Five briefs; D4 is the one that gates a wave

R1 · D4Where does a deterministic safety escalation speak?

Deciding: whether the time-critical safety leaves (the unproductive-strain cluster, a cat's open-mouth mark) speak at capture the moment the rule trips (§03 frame 3b), or only from the Signal safety card on Home (frame 3c). Gates wave 2's design, not wave 1. The breath counter's over-30 threshold line (frame 4d) rides the same ruling.

Options: A — capture-time band + Signal card Recommended — team + Dr. Chen: the rule is deterministic and runs client-side over local rows, so it can speak in the seconds the owner is already looking, with the write committed first, no haptic (silence on safety, guard-enforced), never blocking, and the register structurally reserved for this one class — a cough or a limp can never acquire it. The Signal card still renders as the durable backstop. B — Signal-only Designer's dissent, recorded: capture is the surface the whole app protects; a sheet that can turn urgent teaches owners to brace before logging, and the safety card is where the app already teaches them to look.

Consequence: A adds the §6 escalation-band contract to the W2 spec (band spec, call-script surface, the sex-conditioned copy with its unknown fallback) and both renders in this page become the design authority. B deletes 3b and 4d's callout — and adds a new W2 requirement in their place: the safety card must land within minutes of the third log, which the engine's current refresh cadence does not promise, so B is not free — it buys the calmer sheet with new freshness work. A blocked cat is the case where the difference is measured in hours.

R2Does the grid scale — and the regroup that makes it

Deciding: confirmation of the §01 answer to "does the grid scale?" — grouped scrolling sheet, headers as wayfinding, frequency-honest group order, all symptom families in the one rose tint — plus the two visible regroups: "Symptoms" becomes Tummy, Lethargy moves to Energy & behavior, and Itch/Scratch relocates to Skin & coat as Scratching at W3 (which enum value that tile writes is W3's build call, flagged not made).

Options: A — confirm as drawn Recommended: headers + stable order carry 28 tiles, and the spine arrives a family at a time anyway. B — per-family tints: more scannable at full spine, but it dilutes rose-means-symptom across History/Today and spends the tint channel on wayfinding the headers already do; would need its own exploration round. C — rework the density approach (collapsed families, search) — the escape hatch if A reads as too long on device.

Consequence: A locks the picker shape for every wave's PR-2; the stool tile's segments dropping at full-spine density rides the same call.

R3Saw it / Found it is per-leaf: artifact leaves keep it, witnessed-by-construction leaves drop it

Deciding: the confidence affordance joins the per-leaf contract. Artifact leaves — things discoverable after the fact (vomit, stool, pee outside the box, a lump, a wound, a skin reaction) — keep the full Saw it / Found it window model. Witnessed-by-construction leaves — sounds and behaviors with nothing to find (cough, sneeze, labored breathing, straining, limping, stiffness, hiding, vocal change, seizure, the breath count) — drop the chip pair and write witnessed, with "Change time" covering late logging.

Options: A — adopt the split Recommended: a "Found it" on a cough would stamp a window claim the record cannot hold — the B-448 leak class, avoided by construction. B — keep the chips on every leaf for uniformity: one less rule, but it renders a question with one honest answer.

Consequence: A puts a confidenceModel field in each leaf's §7 contract row and W1 ships cough/sneeze with the two-row confirm in frame 2a.

R4The "frequent for this pet" row

Deciding: whether §06's bounded row ships, and when.

Options: A — park until the grid earns it Recommended — including by its proposer: at W1–W3 density the whole grid is above the fold, so the row spends a permanent row of space to save nothing; revisit at the wave where a pet's grid actually scrolls (W3+), with the row appearing only for pets whose grid exceeds the fold. B — ship it at W1: earliest value for the one real user, whose cough logging is exactly the case. C — drop it: the stable grid is the feature; the row is a second place for the same tile.

Consequence: A keeps wave-1 scope at two tiles + confirm; the row gets its own later mock beat only if promoted.

R5 · Q4The licensing fence — the outstanding one-line confirmation

Deciding: the D8-provisional Q4 posture, confirmed explicitly: derived indices are reported as "computed from logged events using the item definitions," never as the validated instrument; no licensed instrument wording (CBPI/LOAD/FMPI/VetMetrica) reproduced in-app; and no numeric itch scale UI, ever (the PVAS numbers-break-the-scale finding). This page complies by construction — the itch context flags (at night · woke him from sleep · kept going despite distraction) will render as word chips when they ship, never as a 0–10.

Options: A — confirm Recommended — team + T&S position · B — amend (name the change).

Consequence: A closes Q4 and the fence governs all waves without another pass.
