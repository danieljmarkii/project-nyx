# Pet research

The PM's own pets: analyses of their records, vet panel reads, and summaries to bring to their vet. One folder per pet.

This folder is personal record keeping, separate from `docs/research/`, which holds product evidence for Culprit. Nothing here is a product decision, and nothing here is a diagnosis. Each file is a dated snapshot of what the record showed that day; correct it with a dated note at the foot, never in place.

**Filename:** `YYYY-MM-DD-short-slug.md`, under the pet's folder.
