Option H — "The flowsheet, packed" F, WITH THE SPACE SPENT ON NAMES

F's class rows, two fixes. Rows are content-gated — a class with nothing logged today doesn't render a row (an empty row is the wasted space you saw). And the reclaimed room is spent on what round-4 F never told you: the names and the times — which food, which drug, when. A symptom class, when present, always renders and always leads.

Option J — "The briefing" STAT TILES, ZERO EMPTY SPACE

Home's intelligence-surface register in miniature: a 2×2 grid of fact tiles, content-gated like the briefing's cards — each tile is a number with its recency, and a tile only exists when it carries information today. The symptom tile, when it exists, is always top-left (safety leads, Principle 3). The most glanceable of the three; the trade is that times-of-day detail compresses to "last at."

The team's read across H / I / J

What each tradesH groups by class — best for "did the meds happen?"; loses chronology. I keeps chronology and names — best for "what happened today?"; a heavy day overflows soonest. J is fastest at a glance and never wastes a pixel; compresses times to "last at," so it tells you that, not when-in-the-day.
