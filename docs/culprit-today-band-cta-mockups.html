Culprit · The Daily Recap · design decision

Today band — one door

The Home “Today” band has two ways into the full-day recap, and they land on the same screen: the Full day › door up top, and a N more events today → link at the bottom of the capped rows. Both read as “the door to the full day.” Pick which one survives — and what happens to the count the second one was carrying.

The call

Deciding
What happens to N more events today →, given Full day › stays the one primary CTA.
Recommendation
Option A Demote to a quiet caption. It removes the second door — the actual redundancy — while keeping the one thing the line honestly carries: how many events sit below the 3-row cap. The count line reports category totals (“3 meals · 1 dose”), not what’s hidden, so a blunt delete costs a sliver of honesty for owners like Sam who log many small meals a day.
Consequence
Either way, Full day › becomes the sole door and the card reads as one CTA. A is built and on the branch; flipping to B is a one-line change (delete the caption) if you’d rather have the blunt cut.
