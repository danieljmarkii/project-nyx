# DR-4 — the primer, full-screen and clean (CUL-21)

**Date:** 2026-08-15

Rebuilds the notification **primer** — the one screen between an owner's "turn this on" and the single OS permission prompt — from the B-661 PR 3 bottom sheet into the design-locked full-screen "c2, clean" surface. Spec: `docs/nyx-daily-recap-requirements.md` §5 / R-7. Design lock: `docs/culprit-daily-recap-mockups.html` §4. Shipped via **#654** (draft).

## What shipped

- **`components/notifications/NotificationPrimer.tsx`** (renamed from `…Sheet.tsx`, `git mv`) — a full-screen `Modal` on the daylight ground with a dark **night-miniature hero card**: teal `Evening summary` eyebrow, serif moonlight lead, a 3-node mini-spine (Breakfast · Apoquel · Dinner) of a **generic warm day** drawn with the night category tints and a connecting thread. Headline **c2 "The day, read back to you."**, one body paragraph, `Turn on` / `Not now`. The content sits in a `ScrollView` (contentContainerStyle `flexGrow:1`) so the CTAs pin to the bottom at normal sizes but "Not now" stays reachable at max Dynamic Type.
- **Per-category primer descriptor** on the category registry (`lib/notifications.ts`) — `NotificationPrimerDescriptor` (`heroLabel` / `heroLead(petName)` / `headline` / `body` / `miniSpine`). All copy lives here, so the component is copy-free and every invocation (settings toggle, the DR-3 offer, future categories) opens the same surface with the category's own descriptor. Only `heroLead` takes the pet name → **multi-pet renders the neutral "The day, gathered up."**
- **`app/settings/notifications.tsx`** — import/JSX rename; the **relocated lock-screen privacy promise** (a footnote where the owner examines the feature, not the pitch); the **fresh-decliner** denied-copy fix (**closes B-666**).
- **`constants/theme.ts`** — minted `colorEventMedicationOnNight` (`#93ADCB`, the hero's med node; AA 7.9:1/6.4:1) and `colorMoonlitTeal` (`#4FD8C4`, the decorative eyebrow; AAA 10.4:1 on night). Neither is the interactive `colorAccent`.

## Decisions

- **Killed per PM, not deferred:** the notification-preview chip and the fine-print block. The one consent-honesty line ("Your phone will ask once — change it any time") survives folded into the body — the OS dialog still never surprises.
- **Eyebrow is `colorMoonlitTeal`, not `colorAccent`.** Both reviewers flagged reusing the interactive accent for decorative text (it violates the theme's own "accent = tappable/live, never decorative" rule, which this PR extends). Minted the mock's `#4FD8C4` night tone instead, paralleling `colorEventMedicationOnNight`.
- **`colorEventMedicationOnNight` minted here** (DR-1 also specs it): DR-4 is parallel-safe and needs the med tint now; the token is additive, so DR-1 finds it already present.
