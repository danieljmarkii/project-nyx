## Decisions made

- **Failure posture: render nothing, not a partial card.** If the core reads (regimens / doses / items) throw, the loader returns `null` and Home draws no strips. This is the SAFE direction: a regimen card assembled from an unread dose list would print "No dose logged yet today" — reassurance-on-absence (N4) over a read that merely failed. The pet-level **intake-decline** read is a separate safety lane (it also leads the Signal zone), so it is best-effort and defaults `false` on its own failure without taking the strip down — the exact scoping `dietTrialFacts` gives it.
- **Resolve inline in Home, not in the hook.** The hook returns the `MedStripInput`; Home calls `resolveMedStrips`. Mirrors `useDietTrial`/`TrialStrip` so the resolver stays visible on-screen and the §8/D9 placement is assertable over source.

## Residuals / carried forward

No component test fabricates state 9 because the resolver cannot emit it; the gate stays as the safe direction if a future input shape ever produces an unattributable candidate.
