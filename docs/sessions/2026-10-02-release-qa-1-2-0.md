## Lessons

- **Run the reviewers' lens on the fix, not just the bug.** Two of the session's own fixes were wrong in a way only the adversarial pass saw. Excluding looks from the Signal's recency check hid a safety row. Skipping looks in the trial outcome made its absence sentence false. Each was right about the rule it applied and wrong about a neighbouring surface.
- **A gate that holds a row is also a gate that holds a correction.** The parent gate was right for an allowed food (a terminal refusal) and wrong for a dose (a retryable one), because "the parent has not landed" also reads true of a parent the server already holds with an edit in flight. Hold a child only where sending it early costs more than holding it.
- **A test machine shared with agents is not CI.** One pre-push run failed at a load average near 12 with three agents running tests beside it. The fix was a per-file budget on the one test that sits at half its timeout, not a re-run.
