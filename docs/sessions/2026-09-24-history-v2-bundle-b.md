**The second-order effect, and the lesson (C-43).** Moving the default to the safe side (unknown reads as still) turned every test that asserted "no motion" through the real hook into a test of nothing. Measured on the vomit section: with the fetch frame counted as a wait (the defect its "no arrival" test was written for), the test goes red when seeded to motion on and stays green unseeded. The two section suites that assert the arrival with the real hook are now seeded explicitly; no global test prime, so a future test that forgets gets still frames and fails loudly on a positive assertion. When a default moves to the safe side, find the negative assertions that run through it and seed the unsafe side first.
