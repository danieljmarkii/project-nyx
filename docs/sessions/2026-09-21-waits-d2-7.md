## The review

The `code-reviewer` (one round, 62 tool uses) returned **ship-ready** with two
cleanups, both taken: the namespace `index.ts` header still said "empty at D2-0, the
first lane is D2-3" (rewritten — the first modules are the waits); a `+ 2` literal
beside a token in `EventSilhouette` (now `spaceMicro * 2`). It re-ran the flag-off
mutation independently (`ColdStartOverlay` ungated → the `mustContain` floor reds),
traced the fetch-vs-request state machine in both analysis sections for a path where
the hardcoded `working` on the pending branch could mislabel a fetch (none: every
`status: 'pending'` write is batched with `setWorking(true)` or has a real call in
flight), and judged an adversarial pass unnecessary — no detection, escalation or
AI-read logic moves; only the chrome around it.

## Decisions made in-session

- **The tab bar's height is handed in, not imported.** `NyxTabBar` pulls `PetAvatar`
  and, through it, the Supabase client into anything that imports it; a wait's shape
  must not carry the data layer. `HomeSilhouette` takes `tabBarHeight`; the host
  passes `TAB_HEIGHT` (one definition, now five consumers).
- **`EVENT_HERO_HEIGHT` moved to `lib/eventPhoto.ts`** so the event silhouette and
  the screen answer one question with one constant (C-34) without a component
  importing a route.
- **The report's subtitle stays the shipped one** ("Pulling together the full
  record."). The mock's "Six weeks, every episode, for your vet." claims a window the
  screen does not know.
- **`app/settings/beta.tsx` untouched.** The on-state hint the tripwire named is in
  D2-3's posted plan (and D2-5's); a third edit is a guaranteed conflict for nothing.
  Recorded in the guard's comment.
- **The plan-gate in an unattended session**: the plan was posted on the issue before
  code, as the gate asks; no go-ahead could arrive, so the build proceeded on it with
  every call reversible in review (the D2-1 precedent).
