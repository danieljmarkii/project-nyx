## B-614 PR M5 — the copy + safety pass

Copy-only. **No candidacy / confirmability gate / collapse-predicate / withholding-set

and computes no clinical finding. Every §9 string run through `nyx-voice` +

Files: `lib/medStrip.ts` (the copy helpers), `components/home/MedStrip.tsx` (the confirmed
line + the failure Alert).

### The two named M5 calls

1. **Collapsed-header "today / of N" legibility.** `… · 2 doses logged` →
   **`… · 2 doses logged today`**. A collapsed card means today's cadence is met, so the
   count is a fact about the record *for today*; without "today" the bare count reads as a
   lifetime tally. Still N4 — a counted fact, never "all caught up".

2. **Past-length + refused line composition — RULED.** On a course that is both past its
   typed length (states 6/7) and carries a refused dose (state 8), the single line carries
   the **refusal alone**, and *nothing is lost by it*, because the two facts render in
   DIFFERENT places: the calendar overrun is already in the **header**
   (`day 17 — 3 days past`), and the advisory's action ("check your vet's plan") is
   preserved by the button standing down + the card becoming a tap-through to the Pet tab.
   So the card shows **both** facts — overrun in the header, refusal in the line — and the
   advisory string is *subsumed*, not dropped. This ratifies M1's withholding-wins default
   with the clinical rationale, and replaces the `⚠️ M5 must rule…` comment. Pinned by test.

### The rest of the pass

- **Withholding line register (§6/N3 — the state-8 clinical call).** Leads by clinical
  priority: refused → not-given → unconfirmed. The lead clause carries the "of the last N
  doses" frame; further reasons append as bare counts. A single recent dose reads
  **`Last dose refused`**, not the clumsy "1 of the last 1 dose refused" — the count frame
  earns its place only across several doses. "missed" stays the STATE, never the WORD
  ("not given", N1).
- **Recency lines gained the time-of-day M1 deferred to M5.** State 4 (ongoing):
  `Last dose yesterday, 9:00 PM`. State 5 (ad-hoc): leads with the most-recent dose then the
  window count — `Last dose yesterday, 7:00 PM · 2 in the last 14 days` — and a lone dose is
  just `Last dose Jul 29, 3:00 PM` (no redundant "1 in the last 14 days" tail). New shared
  `recencyPhrase` + a **tz-aware** `clockTime` (mirrors `relativeDay`'s date branch — the
  tests pin it under `'UTC'`, the app reads the device zone), so no B-441-class clock drift.
- **Failure Alert** body → `Please try again in a moment.` (Pattern 8 — honest, calm,
  points at the next action).
- **Confirmed line** stays `Dose logged just now` (a statement about the record, no `!`).
