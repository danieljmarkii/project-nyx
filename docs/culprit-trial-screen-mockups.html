§02

The rules every PR builds under

The pet comes from the route.Every read, door and sheet takes the pet in the link, never whichever pet is active. The screen names its pet.
One resolver, a new layout.Every string comes from the modules that already write it. The screen adds layout, never meaning, and no new count.
The gate travels with the number.When the strip withholds a line, the screen withholds the same line, read from the same field.
Safety replaces the top.The card's own warning, For the call, the doors, then only the card's own action. No ledger and no chart on a safety face.
The ledger is a record.No percentage, streak, grade or "on track". A slip is ink, never rose. A gap is hollow and unshamed. Every row carries its count, in trial weeks.
It only shows.Logging stays on the +. Starting or replacing a trial happens on the Pet tab.
Never quieter than Home when it should escalate, never calmer than Home when it shouldn't.The screen adds no comparison the strip doesn't print.
One door per action.Every trial button lives on the screen. The Pet tab carries a door, never a second set.
Loading is not empty.The screen never says "not on a trial" until the record answered.
