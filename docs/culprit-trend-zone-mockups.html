04

What was ruled

This is no longer a Quick Win.

The label and the Next priority were set against the 2026-06-07 framing, when the reflection card had no gates and the overlap really was cosmetic. Row A is false reassurance on a chronically ill pet, which clinical-guardrails forbids outright. Re-rated 2026-08-22: the Quick Win label is removed and the issue is priority Urgent.

Decision 1 — which shape · RULED: A

Options: A drop Trend's comparison line and the "improving" verdict, keeping chart + bare count (recommended — closes all four cases with no new dependency, and the line only ever adds something when the Signal has deliberately withheld it) · B Trend reads the Signal's findings and inherits the gates (fails open when the cache is absent) · C suppress ③ instead (inverts the safety property — not recommended).

Consequence: A is a contained change to two files and needs no Edge Function redeploy. B couples Home's chart to the Signal cache and re-opens the gate logic client-side. C would ship the bug.

Decision 2 — does the count follow in the same PR · RULED: yes, rides along

Rows C and D are a coherence defect, not a safety one: the two surfaces count different things (episodes vs. rows) about different symptoms. Fixing it means aligning useTrend to the engine's episode collapse and symptom set — which would drop lethargy from the chart, a real loss.

Ruled: both in this PR. As built, that means the Trend card counts episodes through the same lib/symptomEpisodes predicate the engine uses, and picks its subject by current-window episode count rather than a 14-day raw total.

One thing changed against the brief. The brief warned this would drop lethargy from the chart. It did not have to: aligning the selection rule rather than the symptom set fixes the contradiction and keeps lethargy chartable — CORRELATION_SYMPTOM_TYPES scopes food→symptom correlation, not what belongs on a symptom chart. The residual, taken knowingly: when lethargy is dominant the two cards name different symptoms — two true facts, no longer a contradiction now that neither renders a verdict.
