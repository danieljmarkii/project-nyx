01

Round-2 reactions, applied

Heat cells → count pips. Judging light-rose vs mid-rose is guesswork; counting 1–2–3 dots is not. Anywhere round 2 shaded a cell, round 3 draws discrete pips — the encoding the shipped calendar already uses. Intensity ramps are retired app-wide.

"Busy" is a real budget. V1's hero tried to show five things at once. The detail screen gets a hard rule instead: one chart in view at a time; every additional analysis is a module you scroll to or summon. The three variants are three different spends of that budget.

Time-of-day is generalized. Not a symptom-specific trick — a standard module for any event type (itch, vomit, stool, meals, doses), §02 row 3.

02

What else can we honestly report? The metric shelf

Audited against data that already exists on-device. The sharpest finding: the best new metrics aren't new counts — they're new dimensions of the events we already have. Four families: rhythm (when), spacing (how often, how clustered), character (what kind), context (what else was true).

03

Shared anatomy — what every variant agrees on

All three variants are the same six parts in the same order; they differ only in how many modules are open at once. 1 · Headline read (the approved baseline sentence). 2 · The annotated trend (approved D1 chart: stems, meal ticks, change markers). 3 · Analysis modules from the §02 shelf (recency/spacing · time-of-day · character mix). 4 · The days behind the number (tappable → event detail). 5 · Exits (report link; Ask chip, flag-gated). 6 · Coverage line (days-logged denominator, always visible).

DC — Earned modules (the screen sizes itself to the record)

Modules render only past their floors Quiet modules collapse to one honest line Adaptive length

DA's stack, but each module earns its expansion: below its floor it collapses to a one-line explanation of what it's waiting for. A dense record reads like DA; a thin one stays short and honest instead of padding itself with empty charts. Shown here on a low-data case (first vomit in six weeks) — the case that punishes DA with empty modules and punishes DB with dead tabs.

Dr. Chen + Data Scientist — the rules the modules inherit Recency is a fact, never a win ("10 days since" sits beside the coverage line, and no quiet stretch ever renders as celebration).
