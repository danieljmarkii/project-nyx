Notes

Rules under the frames

Intake is never preferenceNothing started from a contact changes how eating is read. "Try warming the food" can be noted or started as a food change, but a decline keeps its full weight on Home and in the report (Sam).
Awareness only (PM ruling)A contact may add a context line to a warning. It never removes, softens, delays, reorders or rewords one, and it is never an exam for the care state.
The schema call, nudgedRuling 1 ties instructions to contacts, and the instructions table keys on a visit row. A channel on the visit record lets that key work unchanged; a separate contacts table means instructions need a second parent. This tilts toward the channel field with a reader guard. Still the PM's call.
Lab results by emailA results PDF is clinical. Whether a document marked results is listed on the report is a Vet Files question (its D14), not drawn here (Sam).
Free, alwaysContacts, attachments, instructions and the report line are core logging: Pets > $.
UnchangedBooking, Get ready, At the vet, Home's appointment strip, every existing visit (read as At the clinic). No model reads screenshots, notes or typed instructions. Culprit never reads Messages or an inbox.
