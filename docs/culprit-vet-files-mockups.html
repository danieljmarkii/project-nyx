Guardrail — D7, the report windowLinking or unlinking a visit here edits only this document’s reference. It never creates, dates, or re-dates a vet visit — and so can never move the vet report’s “since last visit” window.
Guardrail — what the app never doesNo AI reads, no auto-filled diagnosis, no “this lab looks normal.” In v1 the app stores, shows, and shares. Understanding stays with the vet (Phase 2 is separately gated).
Privacy plumbing (invisible here, real in build)EXIF/GPS stripped on upload; signed URLs are short-lived and request-time; the new bucket ships owner-scoped with size + MIME limits on day one; delete-account purges the corpus.
Open call — the ⋯ menuOverflow currently holds only “Delete.” If reactions want rename/re-type up there instead of inline rows, say so — the detail card slims down accordingly.
