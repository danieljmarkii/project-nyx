Landing hero, after the ping

Four treatments for the unauthenticated brand moment once the ring-train Signal ping comes off the Landing. The whorl ground echoes what getculprit.app already ships — the site is the proof the motif reads as craft standing perfectly still.

Sr. Product Designer · 2026-07-26 · Subject: app/(auth)/index.tsx (the Landing hero). The login form's mark (AuthBrandMark) is already static and is untouched by every option here.

Why we're here. The three-ring radar ping (B-322, re-choreographed twice) still isn't right on device, and the effort spent is real. But there's a second reason to remove it that matters more than the stutter: the pulse is semantically empty on this screen. The pulse contract (spec §3) defines live as "a fresh finding the owner hasn't seen." A logged-out Landing has no findings — the Landing hero hard-codes live as decoration. Removing it isn't a retreat from a motion we couldn't build; it's removing a motion that was never saying anything.

The motion question, answered honestly. One motion mechanism is already proven on this hardware: WhorlSpinner's slow continuous rotations (native-driver, one loop restart per 9–25s period) shipped in N3 and play clean. The fragile shape is the ping — three staggered loops re-arming from the JS thread every 2.6s, so any stall lands mid-fade where the eye catches it. So "can we get motion right?" — yes, but only the slow-drift kind, and only if we want it (Option D). The radar ping is the shape to abandon.

Option A — zero-risk baseline The quiet moon

The shipped hero with the ping simply off — carved moon, crisp static Signal dot, aurora and starfield untouched. This is exactly what reduced-motion users see today, so it is already designed, already tested, already on-brand.

Cost: one prop. Risk: none. But: the hero loses the one element that connected it to the website's richer night, and the screen can read a touch bare at full device scale.

Option B — designer recommendation The whorl ground

The site's watermark brought home: hero-scale whorl ridges behind the moon, drawn in night-elevated indigo at low opacity — texture, not state. The moon keeps its place as the mark (it is the app icon; the first launch should show the icon's mark), and the whorl does what the brand system documented it for: the secondary "whodunit" texture. Someone who lands here from getculprit.app sees the same night.

Static by conviction, not concession: in-app, a turning whorl means "working on the pet's behalf" (it's the loading mark). Nothing is happening on the Landing — so the whorl stands still here, exactly as it does on the site. Teal stays confined to the Signal dot.

Option C — the literal read, argued against The whorl as the mark

"A whorl style logo" taken literally: the motif itself replaces the moon as the hero graphic. Included honestly so the choice is visible — and here is the case against it: the app icon on the owner's home screen is the carved moon. The first screen after tapping that icon should show the icon's mark, not its supporting texture. The brand system also deliberately keeps the whorl out of the identity slot ("kept out of the app icon") so the primary mark stays clean.

Also: at hero scale the ridges put a lot of teal on screen as decoration — the exact thing the 2026-07-12 QA pass removed.

Option D — the motion option, if we want one The whorl drift

Option B with the ridges counter-rotating at 70s/100s (this page animates it — watch the arcs). This is the proven mechanism: WhorlSpinner's continuous native-driver rotation, whose loop restarts land once per period instead of three times per 2.6s. It will not stutter the way the ping does. Reduced-motion renders Option B exactly.

The reservation is register, not feasibility: in-app, a moving whorl is the loading gesture — it says "working." The Landing isn't working on anything. If B feels too still on the PM's device, D is one animation layer away on the same composition — which makes B the safe first ship.

Designer verdict

Ship Option B. Static is the semantically honest choice here, and the website is the existence proof it's beautiful.

The ping failed twice on device, but the deeper problem is that it never meant anything on this screen — the pulse contract ties it to an unseen finding, and a logged-out screen has none. The whorl ground gives the hero the richness the ping was trying to add, in the motif the brand system already reserved for exactly this job, with continuity from the marketing site into first launch. If the still frame underwhelms on-device, Option D is a one-layer addition to the identical composition — so choosing B now forecloses nothing.
