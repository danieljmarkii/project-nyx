§4 · When it says nothing, and why

The silence states

Same discipline as the shipped flag: every uncertainty suppresses; nothing ever reassures. There is no "this food is fine" state anywhere in this feature.

no active trial

No trial running

Nothing to be off. The whole surface is inert outside a trial.

unknown

Trial list not loaded yet

Fresh install, mid-sync, offline cold start — an unhydrated list must not be read as an empty one.

out_of_window

Feeding outside the trial dates

A backfilled meal from before the trial started says nothing about the trial.

off_diet_protein

Panel read, protein conflict

The stronger shipped flag fires instead (frame 1). Never both — one heads-up per moment.

permitted

On the list

Nothing renders. A permitted food is never praised — absence of a flag is not a verdict (G2).

ledger spent

Already told this trial

One heads-up per food per trial, counted in heads-ups given — never in meals fed.

§5 · The words, and the calls

Register, and what's left to rule

Proposed strings — round 1

Headline: This one isn’t on Biscuit’s trial list.

Detail (B): The meal’s saved, and it counts in the trial record. If your vet okayed this food, adding it to the list keeps the record straight.

Add line (B): + Add to the trial list

Detail (A): …you can add it to the list from the food’s page.

What it never says, at any coverage, in any state: off-diet · contaminant (nobody read this food's panel — the claim is about the list, never the food's contents) · no conflicts found · anything that scolds the owner or judges the feeding. The meal is already saved and the copy says so first.

Decision 1 — does the library's "positive marking only" rule bind this surface?

B-616 D2 ruled the library never marks a food off-diet. This card is a one-time note about a feeding, not a standing mark on a food — the register the exposures screen already uses. The frames above are the argument; if the rule binds log-time too, neither variant ships.

Decision 2 — variant A or B?

B is the ratified escape hatch in place; A respects the card's fourth-affordance warning. The Designer flag is genuine — rule it by how the frames read, not by the argument.

Decision 3 — stop firing past the trial's effective end? (B-595)

Nothing auto-ends a trial, so "active" long outlives the target. Proposal: both log-time flags (this one and the shipped protein flag) gate on the one shared "still genuinely running" definition — one fix, both flags, ruled here rather than left open.
