What "build fidelity" changed

Between round 1 and the build, five things moved. None is a new decision — each is the shipped spec catching up with a round-1 sketch. They're listed here because a frame that looks different from round 1 is different on purpose.

Refinements now baked into every frame below

  • The empty-stomach band is 6h+, not 4h+ (D10, CUL-16, Dr. Chen). The label asserts physiology — at 4h a solid meal is still ≳half in the stomach — so the boundary is specificity-first. The middle band is now 30 min–6h.

Why the fewer direction is genuinely hard (PR 3 adversarial rounds — the input to R2-5)

  • The mechanism is sound where it fires: vomit-only pooling (the round-2 masking fix) means a rising vomit can only ever fire the more direction — a resolving co-symptom can never mask it. A worsening trial always surfaces.
  • The reassuring residual can't be removed at n=1: symptom-logging attrition behind sustained meal-logging (diligent vomit-logging early, tapering later, while meals keep confirming) mints a false "fewer" ~14–35% of the time. No detector can tell "stopped logging vomits" from "vomits stopped" — the app-wide didn't-log ≠ didn't-happen limit, here on the reassuring side.
  • Option B is one line (changedMaterially = gate && moreDuringTrial) and closes the residual by never minting the reassuring card. Option A ships the full wedge with the residual documented + the RTM expand. Dr. Chen adjudicates; the lane is dark (G10) until.
